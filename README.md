换成自研随机数生成器后，重启前后输出了同一串密钥，重播种也没能挽回：一，重播种直接替换状态而不是把新熵与旧状态一起派生；二，生成后不推进状态，重复调用得到同一串字节；三，序列化不写版本号，跨版本反序列化错位；四，反序列化不校验校验和，位翻转被接受；五，预测抵抗刷新不清除旧状态，旧状态仍可推进；六，熵不足时不报错而是用零补齐；七，健康检查不看重播种间隔，长期不重播种仍报健康；八，生成接口允许零长度请求但不推进状态，破坏调用序；九，反序列化允许把状态回滚到更早版本；十，批量生成复用同一状态，第二个请求延续第一个请求的输出。请实现 drbg/core.py 中恰好 8 个桩：instantiate、generate、reseed、serialize、deserialize、predict_resistance、check_health、drbg_batch，并用固定向量、状态推进、不可回滚、重播种分离、序列化往返、批量独立等契约验证。drbg/core.py 是核心，tests/unit/test_core.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。
